# Setup
**Windows** : 
- Install [NodeJS](https://nodejs.org/en/download) (at the bottom of the screen choose **Windows Installer.msi**)
- Create a new folder in your files
- Right click and choose "Open in terminal"
- Paste in `git clone https://github.com/Cyroshadow/fire-detector-IoT.git` and hit enter
- Paste in `npm install` and hit enter, *wait for it to finish*

# How to run it
- Right click the folder you installed it in and choose "Open in terminal"
- Paste in `npm run dev` and hit enter, *wait for it to finish*
- Go to your browser and paste `http://localhost:5173`

# How to stop it
Press Ctrl + c in the terminal or just close the terminal window
